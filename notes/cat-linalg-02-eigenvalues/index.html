Eigenvalues as Natural Transformations

A scalar eigenvalue assigns one number to one vector. A categorical eigenvalue assigns a coherent family of maps to every object at once. That coherence has a name: naturality.

The previous post introduced $\operatorname{Rep}(S)$: the category of objects equipped with a chosen structure map $s_M : M \to S(M)$. Any morphism $M \to S(M)$ qualifies, so $\operatorname{Rep}(S)$ is large and undifferentiated. The linear algebraic eigenvalue equation $Tv = \mu v$ is more specific: the scalar $\mu$ determines the action on all vectors simultaneously, not just on one chosen vector. The categorical analogue of this specificity is a natural transformation.

What a scalar eigenvalue really provides

In ordinary linear algebra, once $\mu$ is fixed, the map $v \mapsto \mu v$ is defined for every $v \in V$ at once. It is not a separate choice for each $v$. Moreover, it interacts correctly with linear maps: if $f : V \to W$ is linear and $\mu$ acts on both, then $f(\mu v) = \mu f(v)$. This coherence is exactly what naturality encodes.

The definition of a categorified eigenvalue

Definition. A categorified eigenvalue for $S$ is a natural transformation

$$\lambda : \operatorname{id}_{\mathcal{A}} \Rightarrow S.$$

For every object $M \in \mathcal{A}$, the component $\lambda_M : M \to S(M)$ is a specific morphism. Naturality requires that for every morphism $f : M \to N$ in $\mathcal{A}$,

$$S(f) \circ \lambda_M = \lambda_N \circ f.$$

This is the same commutativity condition as for morphisms in $\operatorname{Rep}(S)$, but now it holds for all morphisms in $\mathcal{A}$, not just the ones we select.

Example. Take $\mathcal{A} = \operatorname{Vect}_k$ and $S = \operatorname{id}$. A natural transformation $\lambda : \operatorname{id} \Rightarrow \operatorname{id}$ assigns to each vector space $V$ a linear map $\lambda_V : V \to V$, naturally in $V$. By the Yoneda lemma, such a transformation is determined by a scalar $\mu \in k$, acting as multiplication by $\mu$ on each $V$. So in this case, categorified eigenvalues are literally scalars. The definition recovers the classical notion.

The canonical eigenobject category

Every object $M \in \mathcal{A}$ together with the component $\lambda_M$ gives a representation $(M, \lambda_M) \in \operatorname{Rep}(S)$.

Definition. The canonical $\lambda$-eigenobject category is

$$\operatorname{Eig}_\lambda(S) = \{(M, \lambda_M) : M \in \mathcal{A}\} \subseteq \operatorname{Rep}(S).$$

A morphism $(M, \lambda_M) \to (N, \lambda_N)$ in $\operatorname{Eig}_\lambda(S)$ is any morphism $f : M \to N$ in $\mathcal{A}$. The compatibility condition $S(f) \circ \lambda_M = \lambda_N \circ f$ is automatically satisfied by naturality of $\lambda$.

This observation yields the main structural result of this post.

Theorem. The forgetful functor $U : \operatorname{Eig}_\lambda(S) \to \mathcal{A}$, sending $(M, \lambda_M) \mapsto M$, is an isomorphism of categories.

Proof. The functor $U$ is the identity on objects (every $M \in \mathcal{A}$ appears as $(M, \lambda_M)$) and the identity on morphisms (every morphism in $\mathcal{A}$ satisfies the eigenobject compatibility by naturality). An inverse functor sends $M$ to $(M, \lambda_M)$ and acts as the identity on morphisms. Both composites are the identity. $\square$

Why this result is counterintuitive

In ordinary linear algebra, an eigenspace $E_\mu(T) \subseteq V$ is a proper subspace (smaller than $V$, except in degenerate cases). The theorem says that the categorical eigenobject category is not smaller than $\mathcal{A}$; it is isomorphic to all of it.

This is not a failure of the definition. It reflects the fact that a natural transformation $\lambda$ attaches eigenstructure to every object uniformly. There is no object left out, so no object is excluded from the eigenobject category.

The selectivity of classical eigenspaces arises because not every vector satisfies $Tv = \mu v$. At the categorical level, the structure map is not a condition to be satisfied; it is data to be supplied. A natural transformation supplies it for every object simultaneously.

What differs between $\operatorname{Rep}(S)$ and $\operatorname{Eig}_\lambda(S)$

The difference is not in the objects or morphisms that appear. It is in the source of the structure maps.

In $\operatorname{Rep}(S)$: each object $(M, s_M)$ carries a map $s_M : M \to S(M)$ chosen independently for each $M$.

In $\operatorname{Eig}_\lambda(S)$: each object $(M, \lambda_M)$ carries the specific map $\lambda_M$ determined globally by the natural transformation $\lambda$.

The structure is more rigid in $\operatorname{Eig}_\lambda(S)$, which is exactly what makes it the correct analogue of a classical eigenspace.

The next question

The natural transformation $\lambda$ acts on $M$ once to give $\lambda_M : M \to S(M)$. It can also be applied again, to $S(M)$, giving $\lambda_{S(M)} : S(M) \to S^2(M)$. Composing, one gets a map $M \to S^2(M)$. This is the beginning of an orbit tower, which is the subject of the next post.
