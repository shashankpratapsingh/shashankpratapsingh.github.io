Categorified Functionals and Transpose

A linear functional is a map from a vector space to the ground field. Its categorical analogue is a k-linear functor to vector spaces. Transposition, which reverses direction, becomes precomposition.

The first half of this series established the object side of categorified linear algebra: representations, eigenobjects, orbit towers, commuting endofunctors, and filtrations. The second half develops the functional side. The organizing question is: if a $k$-linear category plays the role of a vector space, what plays the role of a linear functional?

Categorified functionals

A linear functional on a vector space $V$ is a linear map $V \to k$. Replacing $V$ by a $k$-linear category $\mathcal{A}$ and $k$ by the category of $k$-vector spaces, the direct analogue is a $k$-linear functor

$$F : \mathcal{A} \to \operatorname{Vect}_k.$$

Definition. The categorified dual of $\mathcal{A}$ is

$$\mathcal{A}^* = \operatorname{Fun}_k(\mathcal{A}, \operatorname{Vect}_k),$$

the category of $k$-linear functors from $\mathcal{A}$ to $\operatorname{Vect}_k$, with natural transformations as morphisms.

The objects of $\mathcal{A}^*$ are the categorified functionals.

Example. For any object $M \in \mathcal{A}$, the representable functor $\operatorname{Hom}_{\mathcal{A}}(M, -)$ is a $k$-linear functor $\mathcal{A} \to \operatorname{Vect}_k$. It is a categorified functional. The Yoneda lemma says that natural transformations between representable functors are in bijection with morphisms in $\mathcal{A}$, so the representable functionals encode the morphism structure of $\mathcal{A}$ faithfully.

Transpose as precomposition

For a linear map $L : V \to W$, the transpose $L^* : W^* \to V^*$ is defined by precomposition: given a functional $F : W \to k$, the functional $L^*(F) = F \circ L$ is a functional on $V$. The direction reverses because precomposition reverses direction.

The categorical definition is identical in form.

Definition. For a $k$-linear functor $L : \mathcal{A} \to \mathcal{B}$, the transpose is

$$L^* : \mathcal{B}^* \to \mathcal{A}^*,$$

defined by $L^*(F) = F \circ L$ for each $F \in \mathcal{B}^*$. On a natural transformation $\eta : F \Rightarrow G$, the transpose gives $L^*(\eta) = \eta_L$, the whiskering of $\eta$ by $L$.

Theorem. For composable $k$-linear functors $\mathcal{A} \xrightarrow{L} \mathcal{B} \xrightarrow{K} \mathcal{C}$,

$$(KL)^* = L^* K^*.$$

Proof. For $F \in \mathcal{C}^*$, we compute $(KL)^*(F) = F \circ (KL) = (F \circ K) \circ L = L^*(K^*(F))$, using associativity of composition. $\square$

In particular, for endofunctors $S, T : \mathcal{A} \to \mathcal{A}$,

$$(ST)^* = T^* S^*.$$

The order reverses. This is not an artifact; it is the entire content of transpose. A functional that first applies $S$ then applies $T$ is the same as first transposing $T$ (to act on functionals) and then transposing $S$.

The double dual

For a finite-dimensional vector space $V$, the canonical map $V \to V^{**}$ sending $v$ to the evaluation functional $F \mapsto F(v)$ is an isomorphism.

Definition. The double dual of $\mathcal{A}$ is

$$\mathcal{A}^{**} = \operatorname{Fun}_k(\mathcal{A}^*, \operatorname{Vect}_k).$$

There is a canonical $k$-linear functor

$$J_{\mathcal{A}} : \mathcal{A} \to \mathcal{A}^{**}$$

defined by $J_{\mathcal{A}}(M)(F) = F(M)$ for $M \in \mathcal{A}$ and $F \in \mathcal{A}^*$. On morphisms, $J_{\mathcal{A}}(f)_F = F(f)$ for $f : M \to N$.

Proposition. The assignment $J_{\mathcal{A}}$ is a $k$-linear functor.

Proof. For a natural transformation $\eta : F \Rightarrow G$ in $\mathcal{A}^*$ and a morphism $f : M \to N$ in $\mathcal{A}$, naturality of $\eta$ gives $\eta_N \circ F(f) = G(f) \circ \eta_M$. This is exactly the naturality condition for $J_{\mathcal{A}}(f) : J_{\mathcal{A}}(M) \Rightarrow J_{\mathcal{A}}(N)$ to be a natural transformation. $\square$

Definition. A $k$-linear category $\mathcal{A}$ is reflexive if $J_{\mathcal{A}} : \mathcal{A} \to \mathcal{A}^{**}$ is an equivalence of categories.

Unlike the finite-dimensional case, reflexivity is not automatic. It is a property that must be verified.

Why this matters for eigenstructure

The natural transformation $\lambda : \operatorname{id}_{\mathcal{A}} \Rightarrow S$ lives on the object side. Applying a functional $F : \mathcal{A} \to \operatorname{Vect}_k$ to the component $\lambda_M$ gives a linear map $F(\lambda_M) : F(M) \to F(S(M))$. This is a structure map on the functional $F$, and it points toward the notion of an eigenfunctional. The next post makes that precise.
