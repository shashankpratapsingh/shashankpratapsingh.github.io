Thoughts on Mathematical Visualization

Visualizing abstract mathematical structures has always been a challenge. Recently, I’ve been exploring ways to represent tensor categories through diagrams and computational tools.

The Challenge

Traditional representation theory relies heavily on symbolic manipulation, but there’s immense value in developing visual intuition for these structures.

Approaches

Some techniques I’ve found useful:

  • Quiver diagrams for module categories
  • String diagrams for morphisms in tensor categories
  • Computational visualization using SageMath

Future Directions

I’m particularly interested in developing interactive visualizations that can help students build intuition for non-semisimple categories.
