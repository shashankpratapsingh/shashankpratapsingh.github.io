This is an example of how to create a photo gallery. Each gallery is a separate post in the Photography section.

To create your own gallery:

1. Create a new post: `hugo new photography/your-gallery-name.md`
2. Create a folder for images: `static/assets/images/photography/your-gallery-name/`
3. Add your images to that folder
4. Reference them in the markdown below

## How to Add Images

Simply use standard markdown image syntax:

```markdown
![Image description](/assets/images/photography/your-gallery-name/photo1.jpg)
![Another photo](/assets/images/photography/your-gallery-name/photo2.jpg)
```

The images will display in a clean, scrollable format. Visitors can easily browse through your collection.
